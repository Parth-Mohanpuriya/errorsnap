# errormap Interactive Demo App

A modern, lightweight Express demo application showcasing the **`errormap`** package.

## Features Demonstrated

1. **`AppError`**: Creating structured, meaningful errors with HTTP status codes.
2. **`errorHandler`**: Express middleware providing standardized JSON responses and preventing security stack leaks in production.
3. **`formatError`**: Beautiful, timestamped terminal logging for developers.

---

## Quick Start

```bash
# 1. Navigate to the demo directory
cd errormap-demo-app

# 2. Install dependencies
npm install

# 3. Start the demo server
npm start
```

Open **`http://localhost:3000`** in your browser to interact with the live error simulator.
